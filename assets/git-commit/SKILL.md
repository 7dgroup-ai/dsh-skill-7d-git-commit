# AegisPipe 提交规范适配 Skill

> 事实来源：`references/git-commit-message.md`  
> 服务端兜底：gitlab-01 `pre-receive` hook（当前 MODE=warn，观察期后切换 reject）

## 核心原则

在生成任何 `git commit` 提交信息前，必须按本 skill 校验。客户端预判 + 服务端兜底双保险，避免 push 时被 hook 拦截或产生审计日志。

## 校验清单（生成 commit message 前逐项检查）

### 1. 标签格式

- 必须以 `【类型】` 开头，类型从以下 9 类中选择：
  - 【新增】新增功能、接口、页面、代码文件、配置项、脚本、路由规则、部署资源、测试用例
  - 【修复】修复线上/测试 Bug、运行异常、报错、兼容性问题、逻辑错误、配置错误
  - 【优化】性能调优、代码重构、逻辑精简、交互体验升级、架构优化、资源利用率提升
  - 【调整】修改运行参数、环境配置、样式布局、界面文案、权限规则、路由顺序
  - 【删除】彻底移除废弃代码、无用文件、下线接口、过期脚本、冗余配置、历史资源
  - 【文档】更新注释、README、接口文档、部署手册、运维说明、使用指引、清理过时文档内容
  - 【测试】新增/修改/删除单元测试、接口测试、联调用例、压测脚本、自动化测试代码
  - 【回滚】版本回退、撤销历史提交、恢复原有代码/配置/文档
  - 【合并】分支合并、解决代码冲突、同步分支代码、合入特性分支

### 2. 标题长度

- 去标签后的描述部分 ≤ 50 字符（中文/字母/数字均计 1 字符）
- 超限时必须精简，优先保留「改动对象 + 具体动作」

### 3. 末尾标点

- 标题末尾禁止：`。`（中文句号）、`，`（中文逗号）、`.`（英文句点）、`,`（英文逗号）

### 4. 禁用字符

- 标题或正文禁止出现：`@`、`#`、`$`、`%`、`^`、`&`、`*`、`~`
- 例外：行业通用技术专有名词如 `K8s` 中的 `s` 不影响，`C#` 如需使用须确认无替代表述

### 5. 禁用短语

- 禁止出现：待优化、后续再改、待修改、以后再说、TODO、FIXME、哈哈哈、666
- 禁止临时备注、待办事项、个人情绪、闲聊内容

### 6. 正文行宽

- 正文每行 ≤ 70 字符（数字序号前缀如 `1. ` 不计入）
- 多条改动用数字序号逐条罗列

### 7. 豁免场景

- **Merge commit**：标题以 `Merge ` 开头可豁免标签校验
- **紧急发版**：可在标题或正文加 `[skip-check]` 跳过校验（仍会记录审计日志）

### 8. 句式要求

- 统一使用**动宾短语**，采用客观陈述句
- 必须写明「改动对象 + 具体动作」
- 涉及多环境/多服务时明确标注环境或服务名称
- 追溯标识：关联需求ID-XXX / 关联工单ID-XXX / 关联缺陷ID-XXX（可选，放标题末尾或详情末尾）

## 操作步骤

1. **分析改动内容**：确定改动对象、动作、影响范围
2. **选择标签**：从 9 类中选最匹配的类型
3. **撰写标题**：`【标签】` + 动宾短语描述（≤50 字符，无末尾标点）
4. **撰写详情**（复杂改动时）：标题空一行，数字序号罗列，每行 ≤70 字符
5. **执行校验**：对照本清单逐项检查
6. **不合规则修正**：调整标签、精简描述、移除禁用字符/短语
7. **执行 commit**：使用修正后的 message 执行 `git commit`

## 与 hook 的分层

| 层级 | 位置 | 行为 | 适用阶段 |
|------|------|------|---------|
| 客户端预判 | Kimi Code（本 skill） | 生成 message 前校验，不合规则提示修正 | 日常开发 |
| 服务端兜底 | gitlab-01 pre-receive hook | push 时二次校验，warn 模式告警 / reject 模式拦截 | 观察期 / 硬拦截期 |

## 标准示例

```text
【新增】用户模块新增手机号登录接口
【修复】修复列表分页数据加载异常问题
【优化】重构公共工具类，提升代码执行效率
【调整】修改首页弹窗展示时长与样式
【删除】移除旧版废弃的统计代码文件
【文档】补充支付模块接口注释与使用说明
【测试】新增订单结算场景单元测试用例
【回滚】回退上一版用户权限配置改动
【合并】合并开发分支至主分支，解决代码冲突
```

复杂改动示例：

```text
【文档】全面更新部署相关文档

1. 补充新版容器集群部署流程
2. 移除已下线的网关容器部署章节
3. 修正原有文档配置描述错误
```

## 禁止示例

```text
fix bug                          ❌ 缺标签、纯英文
【新增】改一下                   ❌ 非动宾、对象不明
【新增】新增接口。               ❌ 末尾句号
【新增】配置邮箱 a@b.com         ❌ 含禁用字符 @
【修复】修复登录 TODO 后续处理   ❌ 含禁用短语 TODO
【新增】这个功能差不多可以了     ❌ 口语化、非动宾
```

## 紧急发版绕过

仅在紧急发版流水线场景使用，提交信息中加 `[skip-check]`：

```text
hotfix 修复支付接口超时 [skip-check]
```

> ⚠️ 使用后会记录 `[BYPASS]` 审计日志，非紧急场景禁止滥用。
